# ruhankhanna.github.io

Personal site. Plain HTML, CSS and JavaScript, no build step.

- `index.html` - page content
- `styles.css` - layout and theme (light and dark)
- `main.js` - the interactive demos: athletIQ forecast lab, Indus method walkthrough, quote check, Pan-Out charts

Optional media: add `assets/secret-car.jpg` for the race car section, and `assets/reel.mp4` + `assets/reel-poster.jpg` for the video section. Both sections hide themselves until the files exist.
